# Mentbot

**Comment automation for businesses that sell on Facebook and Instagram.**

When someone comments on a post, Mentbot replies under the comment and sends the commenter a private message in Messenger or Instagram Direct, so a "How much?" turns into a conversation the seller can close.

- Keyword and hashtag rules decide which reply goes out, and each rule can be limited to specific posts
- Auto-like and auto-hide comments
- Telegram alerts when a customer's message sits unread
- No chatbot flows to design

Plans run from $9 to $49 a month by daily comment volume, every plan has every feature, and the 14-day free trial needs no credit card.
